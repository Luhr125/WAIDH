# Shift Runner

Ein kleines Jump-and-Run für den Browser. Erreiche das grüne Portal, ohne rote
Hindernisse zu berühren. Die Tastaturbelegung wechselt alle zehn Sekunden.

## Spielen

Öffne `index.html` in einem modernen Browser und wähle **Spiel starten**. Es
werden keine Pakete und kein Build-Schritt benötigt.

Die aktuelle Steuerung steht immer oberhalb des Spielfelds. Sie wechselt
zwischen:

- Pfeiltasten: `←`, `↑`, `→`
- Buchstaben: `A`, `W`, `D`
- Buchstaben: `J`, `I`, `L`

## Features

- Jump-and-Run-Physik mit Springen und Plattformen
- Rote Hindernisse, Abgründe, drei Versuche und ein Zielportal
- Automatischer Steuerungswechsel alle zehn Sekunden
- Bildschirmtasten für Smartphones und Tablets
- Responsive Spielfläche für Desktop und Smartphone

Entstanden im Hackathon-Repository der Gruppe WAIDH.
