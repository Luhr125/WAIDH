# Signal Sprint

Ein kleines Reaktionsspiel für den Browser: Triff in 30 Sekunden so viele
Signale wie möglich. Mit jedem Treffer wird das Ziel etwas kleiner.

## Spielen

Öffne `index.html` in einem modernen Browser. Es werden keine Pakete und kein
Build-Schritt benötigt.

## Features

- Maus- und Touch-Steuerung
- Responsive Spielfläche für Desktop und Smartphone
- Lokaler Highscore im Browser
- Zugängliche Buttons und Unterstützung für reduzierte Animationen

Entstanden im Hackathon-Repository der Gruppe WAIDH.
